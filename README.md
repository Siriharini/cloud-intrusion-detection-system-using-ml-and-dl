# cloud-intrusion-detection-system-using-ml-and-dl
Cloud-IDS is an advanced intrusion detection system achieving a 99.27% F1-score on the NSL-KDD dataset. It utilizes a hybrid deep learning ensemble (1D-CNN + GRU + Transformer) with weighted risk synthesis to detect DoS, Probe, R2L, and U2R attacks. Features a stratified 80/20 data split and a live dashboard for real-time network mitigation.
